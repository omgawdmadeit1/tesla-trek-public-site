What Trek is

Trek is a treasure-hunt layer for Tesla drivers: curated pins, AR-style map, adventures, and location claims. Tesla native navigation still handles routing. Trek is the hunt + co-pilot layer on top (Grok / chat + in-car browser HUD).

Safety (read first)

Park first for FLEET connect, CLAIM, payments, and long forms. Do not use the browser HUD while driving.
  • Do not interact with the browser HUD while the vehicle is in motion.
  • Driving = voice-only / passenger UI only. Eyes on the road.
  • Use Tesla built-in navigation for actual turn-by-turn.

What you need

  • A Model Y (or any Tesla with browser + Wi‑Fi/LTE)
  • Phone or car GPS (device claims work without Fleet)
  • Optional: Tesla account + Fleet link for “verified” vehicle GPS claims
  • About 5 minutes parked for first setup

1 Open the car HUD

  1. Park the car.
  2. On the center screen, open the web browser.
  3. Go to this address (tap to open on phone; type it in the car):
https://www.tesla-trek.com/car

www is preferred so Fleet login cookies stick. Bookmark it.

You should see the Trek main screen:

  • Header: TREK · SIM/LIVE · Fleet · level
  • Sections: AR Map · Adventures · Rewards
  • Dock: VOICE · CLAIM · NEXT · FLEET · GROK

Bookmark the page (browser star / favorites) for next drives.

2 Allow location (device GPS)

  1. When the browser asks for location permission → Allow.
  2. If claims fail later, check browser location permission, vehicle/phone location services, and a clear GPS lock outdoors.

Device GPS alone is enough for “device” claims. Vehicle GPS via Fleet is for stronger “verified” claims.

3 Explore without connecting Fleet

  1. Tap AR Map — nearby hunt pins / map overlay.
  2. Tap Adventures — Explorer · Premium · Long Haul · Performance.
  3. Pick a mission vibe (or free roam).
  4. Tap NEXT for the next pin / objective.
  5. Use Tesla Nav yourself to drive toward the pin area when it’s safe.

Trek does not replace Tesla navigation. Set the destination in Tesla Nav; use Trek as the hunt checklist and claim layer when you arrive.

4 Claim a pin (parked, within 150 m)

  1. Drive to a pin area using Tesla Nav (safely).
  2. Park within about 150 meters (≈ 500 ft) of the pin.
  3. Wait a few seconds for GPS accuracy to settle.
  4. On the Trek HUD, tap CLAIM.
  5. Allow geolocation if prompted again.
  6. Read the result:
    • sim_verified / device — device GPS close enough (no Fleet)
    • verified — device + Fleet vehicle GPS both within 150 m
    • rejected — too far, bad GPS, or vehicle GPS disagrees
    • pending — wait / retry

Tips for better claims

  • Park first. Don’t claim while rolling.
  • Wait for a stable GPS fix before CLAIM.
  • If rejected “far,” move closer and retry.
  • If Fleet is linked and the car is asleep, wake the car and retry.

5 Optional: Connect Tesla Fleet

Unlocks stronger claims that check your Model Y’s location via Fleet API.

  1. Park.
  2. Tap FLEET on the HUD.
  3. Sign in / consent on Tesla’s page.
  4. Approve vehicle data / location scopes for the Trek app.
  5. Return to the car HUD — pill should show Fleet (not “Fleet off”).

If Fleet shows linked once then “off” after refresh:

  • Use www.tesla-trek.com/car (not a random preview URL)
  • Hard-refresh the page
  • Tap FLEET again and complete consent

Tokens stay on the server (httpOnly cookies). Never share private keys or refresh tokens.

6 Use Grok as co-pilot (optional)

In Grok (phone, car Grok, or Grok Build), try:

  • “Start Trek — free roam”
  • “Next pin for Daytona / Helen / Giga”
  • “Coach me on a 150 m claim”
  • “What’s the difference between device and Fleet verified?”

Grok is the mission brain; the HUD is the big-touch screen.

7 Rewards & adventures

  1. Tap Rewards — claim ledger, badges, export JSON.
  2. Adventures list curated location quests (Explorer → Performance).
  3. Completing claims near pins advances the hunt (progress bar on AR).
  4. Navigate opens maps to the pin’s real lat/lon.
  5. DOGE★ are game stars from GPS claims — not wallet DOGE. Real DOGE pay is optional Starter after on-chain confirm.

Troubleshooting

  • Blank / old HUD — Hard refresh; confirm URL is www.tesla-trek.com/car
  • CLAIM fails / no GPS — Allow location; park outside; wait for lock; retry
  • Always rejected — Too far from pin, or Fleet GPS not near pin; move closer
  • FLEET does nothing — Server should show auth_configured true
  • Linked once then off — Stay on www; reconnect FLEET
  • Vehicle location unavailable — Car may be asleep; wake / unlock / retry
  • Browser slow — Wi‑Fi or strong LTE; close other tabs
