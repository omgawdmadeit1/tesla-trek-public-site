# Try Tesla Trek

Open Trek in Safari on iPhone/iPad or in the car's center-screen browser while parked. Free first; pay only if you want Starter.

1. Open [https://www.tesla-trek.com/car](https://www.tesla-trek.com/car) while parked.
2. Pick an adventure; set the destination in the car's own navigation.
3. Drive toward the pin; use voice only while driving.
4. Park within about 150 m of the pin and claim.

Optional: link a vehicle via Fleet for vehicle-verified GPS claims.
